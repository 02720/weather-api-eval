## 必须处理（P0）

### 1. "50 = 无技巧" 的中心是反直觉的，必须配套标注
- 问题：公认技巧分是 0 = 无技巧。把中心设为 50 虽解决了跨变量/跨时效可比，但业务方会把"50 分"读成"及格/还行"，而它的真实含义是"毫无增量信息"。同一个"只比气候平均好一点"的 16 天预报，在公认尺度约 15 分（很低，正确），在本方案约 55 分（看着还行，误导）。
- 要求（二选一，推荐前者）：
  - A. 保留 50 中心，但页面上把 50 **强制标注为"=气候平均/无技巧基准"**，配颜色/图例，不得裸奔成"50 分"；
  - B. 改用公认约定 0 = 无技巧、100 = 完美、负值 = 反技巧，只修"底部不截断 + 加灾难下界"。同样能消灭假 0，且不牺牲直觉。

### 2. 参照基准缺"持续性(persistence)"对照，短时效可能虚高
- 问题：温度只和"前后 15 天平滑气候平均"比。对 8~16 天没问题；但对 1~4 天，更公平的免费基准往往是"明天=今天"(持续性)，且很多站点持续性比气候平均更难打败。只比气候平均会让短时效温度显得过强。
- 要求：参照基准改为 `max(气候平均, 持续性)`，或至少把持续性也作为对照指标报出来。中长期不受影响，但能让短时效分数更诚实，也堵住"是否在给短时效捧场"的质疑。

## 提醒（P1，建议写入文档）

### 3. 灾难倍数（3× / 4×）是价值判断，需写明
- 温度 RMSE 3 倍、降水雨量 4 倍为何算"灾难"没有天然常数。它对"消灭假 0"的目标几乎无影响（长时效落点在 46~55，离 0 很远），但会左右 0~50 区间内的排名。
- 要求：文档明确标注这是**可调的价值参数**，最好补一句"比最差朴素基准还差多少"的论证，不要默认成标定结果。

### 4. 中长期温度降到 38 是真话，受众要准备好
- "不是模型差、是尺子坏"这句话要打补丁：**降水是尺子坏，温度既是尺子坏、模型也确实一般**（旧尺子把 3°C 误差虚高成 55 分，无物理依据）。中长期温度分变低是诚实修正，不是回归 bug。建议在方案正文与月报口径说明里点明。
