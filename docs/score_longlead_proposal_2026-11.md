## 0. 一句话结论

现在中长期预报的“0 分”，主要不是模型真的考了 0 分，而是三件事叠在一起：

1. **展示层把下半段压成了 0**：原始分低于 21.3（维度分）或 32.5（综合分）就被截成 0；
2. **换算层把“没有技巧”当成了 0 分**：ETS=0（和瞎猜差不多）现在得 0 分，而不是 50 分；
3. **所有时效共用一把“离完美多远”的绝对尺子**：没有“和气候平均比”的参照，16 天的 3°C 误差和 1 天的 3°C 误差被当成同一件事。

建议把评分从“扣分制”改成“技能分”：

> **50 分 = 和气候平均 / 无技巧基准一样；100 分 = 完美；0 分 = 比基准差一个明确的“灾难幅度”。**

按当前数据做影子复算，中长期（8~16 天）降水分中位数可以从 **0~20** 回到 **46~55**，综合分从 **0~18** 回到 **48~51**，并且不再出现“有数据却显示 0”。

## 1. 证据：0 分到底是怎么来的

### 1.1 第一层：展示增益先把下半段压成 0

现行展示层是一个仿射变换：

```
显示分 = 50 + gain × (原始分 − 50)，再截断到 [0, 100]
```

- 维度分：`gain = 1.744` → 原始分低于 **21.33** 就显示 0；
- 综合分：`gain = 2.863` → 原始分低于 **32.53** 就显示 0。

这意味着：一个原始分 13 分的降水格和一个原始分 0 分的降水格，在页面上看起来完全一样；一个原始分 33 分的综合格也会被压成 0。

当前报告里，小时榜降水列的 0 分数量（只数有分数的行）：

| 时效 | 1d | 4d | 8d | 10d | 12d | 14d |
|---|---:|---:|---:|---:|---:|---:|
| 显示 0 的行数 / 有分数的行数 | 5/31 | 10/31 | 18/22 | 20/20 | 10/10 | 10/10 |

其中 **14 天小时榜的 10 家全部显示 0**，但用页面自带的 21 列指标反算，它们的原始降水分为 **10.4 ~ 17.0**（中位 13.5）。这 10 家在页面上的降水差异被整段抹掉了。

综合分也一样：15 天小时榜有 4/9 行显示 0，该桶的原始综合分中位数约 33.9 分；另有 5 行落在 0.0~30.6 的窄带里。它们不是没有分，而是被展示增益压扁了。

> 这不是模型变差，是**刻度坏了**。展示层本来是为了“拉开差距”，但它把 50 当成中心，把下半段整体压扁了。

### 1.2 第二层：每个指标的 50 分不是同一个东西

当前换算斜率 λ 的标定目标是“让每个子分在桶内的跨源 sd = 8 分”，它追求的是**区分度**，不是**分数的含义**。结果是：13 个子分的 50 分对应着完全不同的真实水平。

| 指标 | 现行 50 分对应的指标值 | 当前数据的中位水平（举例） |
|---|---|---|
| `ets` | 0.415 | 日榜 1d 0.30；10d 0.105；16d 0.035 |
| `grade_ets` | 0.284 | 日榜 1d 0.29；10d 0.05；16d 0.01 |
| `amt_mae` | 1.326 | 小时 1d 1.36；10d 1.69；16d 1.79 |
| `acc2` | 76.9% | 小时 1d 90.2%；16d 52.6% |
| `rmse` | 3.41°C | 小时 1d 1.29°C；16d 3.07°C |
| `r` | 0.720 | 小时 1d 0.93；16d 0.59 |
| `slope` | 7.05 倍或 0.142 倍 | 多数在 0.6~1.0 |

看第一行：ETS=0.415 才给 50 分，但日榜 1 天的中位 ETS 只有 0.30，16 天只有 0.035。也就是说：

> 降水维的“50 分”几乎只有最好的短时效模型才够得着；中长期所有模型都被压在 50 以下。  
> 温度维的“50 分”是 RMSE 3.41°C；降水维的“50 分”是 ETS 0.415。这两把尺子根本不是同一个刻度，却被各取一半做综合分。

这就是为什么“降水分低、综合分被拖低”不能简单归因于“降水难报”。**一半是降水确实难，另一半是尺子的零点放错了。**

### 1.3 第三层：固定尺子不区分时效，也没有“气候平均”参照

现行换算里，RMSE 到了 6.8°C 永远得 0 分，ETS 到了 0.415 永远得 50 分，和提前 1 天还是 16 天无关。

但 16 天的 3°C 误差和 1 天的 3°C 误差不是同一件事。用这份存档里的观测做参照：

| 参照（4 站、2026-08~10，前后 15 天平滑气候平均） | RMSE | MAE | ±1°C 命中 | ±2°C 命中 |
|---|---:|---:|---:|---:|
| 逐小时温度 | 1.99°C | 1.55°C | 40.2% | 71.7% |
| 日最高 | 2.25°C | 1.74°C | 37.7% | 69.0% |
| 日最低 | 1.57°C | 1.25°C | 46.6% | 79.5% |

16 天小时榜的模型 RMSE 约 3.0~3.1°C，比气候平均的 1.99°C 还差约 1.5 倍。按“离完美多远”的尺子它是 55 分；按“比气候平均好多少”的尺子，它应该在 50 分以下。现在这个 55 分是**虚高**，不是“被压低”。

反过来，降水在中长期的中位 ETS 只有 0.03~0.10。它确实接近“没有技巧”。按现行尺子给 0~12 分；按“无技巧=50”的尺子，它应该是 50 左右。现在这个 0 分是**虚低**。

### 1.4 第四层：样本少的时候，0 分可能只是一次运气

中长期桶只有 10 家左右，独立雨事件很少。一个空报或一个漏报就能把 ETS 打到 0 或负数。当前页面只检查“指标缺不缺”，不检查“这个桶有没有足够的雨事件”：

- 指标缺失 → 走“剩余权重归一”；
- 指标算得出来但事件很少 → 照常给分，可能是 0；
- 指标真的算不出来 → 也可能显示 0。

这三种状态在页面上没有区分。读者无法知道“0 分”是模型真的差、样本太少，还是展示层截断。

## 2. 第一性原理：一个“准确度分数”到底该量什么

### 2.1 预报的价值，是“比不用预报多提供了多少信息”

如果一个人只知道当地的气候平均，他能做出一个“永远报气候平均”的预报。这个预报没有任何技巧，但也不是“0 分”——它是**基准**。

一个有用的预报，应该回答：

> 比起“只知道气候”，这家多做对了多少？

所以分数的自然刻度是：

- **50 分**：和气候平均 / 无技巧基准一样；
- **100 分**：完美（零误差、全命中）；
- **0 分**：比基准差一个明确的“灾难幅度”（例如误差是气候平均的 3 倍，或雨量误差是平均雨量的 4 倍）。

这样，50 分在所有指标、所有时效上都是同一个意思。温度 50 和降水 50 才可以各取一半做综合分。

### 2.2 先归一化成“技能变量”，再按价值加权

每个指标先变成一个无量纲的技能变量 `s`：

- `s = 0`：无技巧；
- `s = 1`：完美；
- `s = −1`：灾难下界。

然后：

```
子分 = 50 + 50 × s
```

权重只回答“这项指标有多重要”，不再承担“把分数拉到好看范围”的任务。这样就把两件事分开了：

- **刻度**：由物理参照定义，不能为了好看而改；
- **权重**：由价值判断定义，可以讨论、可以审计。

### 2.3 三种“没有数”必须分开

| 状态 | 处理 | 页面显示 |
|---|---|---|
| 指标算不出来（缺测 / 分母为 0） | 缺项，不参与归一 | `—` |
| 指标算得出来，但事件太少 | 不发布正式分，或向 50 收缩 | `样本不足` / 低置信标记 |
| 指标算得出来，且确实无技巧 | 50 分 | `50` |
| 指标比无技巧还差 | 50 分以下，直到 0 | `0~49` |

**“没有证据”不能写成 0 分。** 0 分应该是“有证据表明比基准差很多”，不是“我们不知道”。

## 3. 修改方案

### 3.1 总览：改五件事

| # | 改什么 | 一句话 |
|---|---|---|
| 1 | **参照层** | 温度用“气候平均”做无技巧基准；降水用 ETS=0 和“总是报零雨”做基准 |
| 2 | **换算层** | 所有指标先归一化成技能变量 `s`，再 `50 + 50×s` |
| 3 | **指标取舍** | 降水去掉 POD/FAR 的评分权重（保留明细）；温度把原始 `r` 换成异常相关 `r_anom` |
| 4 | **权重** | 族权重暂不动；新口径跑出来后用精确方差分解审计，只在偏离过大时调整 |
| 5 | **展示与证据** | 展示层下半段不压缩；长时效加雨事件门槛与可靠性收缩，避免噪声把分数打到 0 |

### 3.2 温度维：从“离完美多远”改成“比气候平均好多少”

**参照怎么算**：对每个站、每个目标日期/小时，用该站前后 15 天的观测做平滑气候平均（排除目标日当天）。逐小时按“站 × 小时 × 日期窗口”，日最高/最低按“站 × 日 × 日期窗口”。如果某个窗口观测不足（例如少于 8 个小时 / 5 个日样本），退回该桶的样本均值，并在报告里标注“回退参照”。

> 这是**验证用基准**，不是业务预报。它回答“如果只会报气候平均，能做到什么水平”，不参与模型排名。

**换算公式**（`R` = 参照误差，`a_ref` = 参照命中率）：

| 指标 | 技能变量 / 子分 | 直观含义 |
|---|---|---|
| `rmse` | `r = RMSE / R`；`r≤1` 时 `S=100−50r`，`1<r<3` 时 `S=50×(3−r)/2`，`r≥3` 时 0 | 误差等于气候平均 → 50；误差 3 倍 → 0 |
| `mae` | 同上，`R` 用参照 MAE | 同上 |
| `acc2` / `acc1` | 高于参照：`S=50+50×(a−a_ref)/(100−a_ref)`；低于参照：`S=50−50×(a_ref−a)/a_ref` | 和气候平均一样 → 50；全对 → 100；全错 → 0 |
| `mbe` | `r=|MBE|/R`；`r≤1` 时 `S=100−50r`，`1<r<3` 时 `S=50×(3−r)/2` | 无偏差 → 100；偏差等于气候平均误差 → 50；3 倍 → 0 |
| `mbe_bdisp` | 同上，`R` 用参照 RMSE | 站间偏差离散度越小越好 |
| `r_anom` | `S=50+50×r_anom` | 异常相关 0 → 50；1 → 100；−1 → 0 |
| `slope` | `S=100−25×|log₂(slope)|` | 幅度完美 → 100；4 倍/四分之一 → 50；16 倍 → 0 |

**为什么把 `r` 换成 `r_anom`**：原始 `r` 里混着“季节均值”和“站点气候差异”，中长期只要预报跟着气候走，原始 `r` 就会虚高。异常相关先把气候平均扣掉，再问“起伏同步不同步”，这是中长期更诚实的指标。

**权重**：先保持现行族权重（总体误差 45 / 阈值 20 / 系统偏差 20 / 形态 15），只把 `r` 的 10% 换成 `r_anom`。不凭直觉同时改权重——新尺子上的实际方差贡献还没测出来，先改权重等于用旧地图找新大陆。

### 3.3 降水维：把“无技巧”从 0 分改回 50 分

**参照**：

- 晴雨 ETS：0 = 无技巧（ETS 本身就是基率校正后的技巧分，不需要再构造参照预报）；
- 雨强 `grade_ets`：0 = 无技巧；
- 雨量 `amt_mae`：参照是“永远报零雨”。`amt_mae = Σ|预报−实况| / Σ实况` 正好就是“模型 MAE / 平均雨量”；平均雨量就是“永远报零”的 MAE。

**换算公式**：

| 指标 | 子分 | 直观含义 |
|---|---|---|
| `ets` | `S=50+50×ETS` | 0 → 50；1 → 100；−1 → 0 |
| `grade_ets` | `S=50+50×grade_ETS` | 同上 |
| `amt_mae` | `r=amt_mae`；`r≤1` 时 `S=100−50r`，`1<r<4` 时 `S=50×(4−r)/3`，`r≥4` 时 0 | 和“永远报零”一样 → 50；完美 → 100；4 倍 → 0 |

**例子**：小时 14 天中位 ETS=0.03、`amt_mae`=1.62、`grade_ets`=0。

- 现行：ETS 3.6、雨量 38.9、雨强 0，加权后原始降水约 13.5；展示层再压成 **0**。
- 提案：ETS 51.5、雨量 39.7、雨强 50，加权后 **48.3**。

模型仍然因为“雨量误差是平均雨量的 1.62 倍”被扣到 39.7，也仍然因为“雨强无技巧”只拿 50；但它不再被误判为 0。**48.3 的意思是“略低于气候平均”，不是“灾难”。**

**为什么去掉 POD/FAR 的权重**：

- 它们和 ETS 来自同一张 2×2 列联表（给定 n，列联表只有 3 个自由度，{ETS, POD, FAR} 已经撑满）；
- 当前 POD 的 50 分对应 79% 命中率，FAR 的 50 分对应 66.8% 空报率，这两个锚点和 ETS 的 0 锚点完全不在一个体系；
- 它们只占 10% 权重，去掉后降水族的 60/25/15 原样保留，等于把权重还给 ETS，而不是新开价值判断。

POD/FAR 明细列继续发布，继续画“多报还是漏报”的方向诊断，只是不再冒充独立证据。

### 3.4 综合分：保持 50:50，但加“证据可靠性收缩”

综合分仍是：

```
综合 = (温度分 + 降水分) / 2
```

在新刻度下，50 分终于有统一含义：两维都和气候平均一样。50:50 的名义价值判断不变。

但长时效降水的事件很少，噪声会把降水分打到 0 或 100。建议加一层**连续的可靠性收缩**，而不是硬性降权：

```
B = E / (E + k)
降水_有效 = 50 + B × (降水 − 50)
```

`E` = 该桶内独立观测雨事件数（小时轨 ≥1mm/h 的站-小时；日轨 ≥1mm 的站-日）；`k` 取现行证据门槛（小时 8、日 3）。

- `E=8`：`B=0.5`，一半向无技巧收缩；
- `E=24`：`B=0.75`；
- `E=3`：`B≈0.27`，降水分几乎回到 50，不拖累综合分。

这不是“降水不重要”，而是“证据少的时候，不要让一个噪声样本替整维说话”。证据充足时 `B≈1`，降水分照常起作用。

**长时效证据门槛**（建议值，可调）：

- 小时桶独立雨事件 < 3：降水分判“样本不足”，不发布分数（综合分为 `—`，温度分照常可见）；
- 日桶独立雨日 < 2：同上；
- 3~7 个雨事件 / 2 个雨日：发布分数，但加“低证据”标记并按上面的 `B` 收缩；
- ≥8 / ≥3：正常发布。

这样，长时效的“0 分”会变成“样本不足”或“接近 50”，而不是假 0。

### 3.5 展示层：下半段不再压缩

建议把展示映射改成：

```
s ≥ 50：显示 = 50 + gain_hi × (s − 50)
s < 50：显示 = s（原样，不再乘增益）
最终仍截断到 [0, 100]，但不允许“原始分 > 0 却显示 0”
```

`gain_hi` 由新口径的 P99.5 映到 95 反解（不再映到 98，留 5 分上端留白）。这样：

- 原始 43 分 → 显示 43 分，不再变 0；
- 原始 60 分 → 显示约 68 分，保留上端的视觉区分；
- 原始 100 分 → 显示 100 分；
- 只要原始分 > 0，显示分就 > 0。

如果希望更保守，也可以**完全取消展示增益**，直接显示原始 0~100 技能分。两种都可以；推荐前者，因为页面已经习惯了“上半段拉开”的视觉语言，但下半段必须恢复原样。

### 3.6 权重：先不动，再用数据审计

现行权重表是价值判断，已经过多轮复核。新刻度会改变各指标的跨源离散度，所以**不能凭旧数据的直觉同时改权重**。

建议分两步：

1. **先按现行族权重上线新刻度**：
   - 温度：总体误差 45（RMSE 35 / MAE 10）、阈值 20（±2°C 16 / ±1°C 4）、系统偏差 20（MBE 15 / 站间 5）、形态 15（异常相关 10 / 斜率 5）；
   - 降水：晴雨 60（ETS）、雨量 25、雨强 15。
2. **跑完后用 `exact_variance_contribution` 审计**：每项对综合分方差的真实贡献是否在名义权重的 **0.75~1.33 倍**以内。超出范围的项才调整，并在报告里写明“这是价值判断的调整，不是标定修正”。

这样既回应了“权重分配”，又不会在没有新数据前拍脑袋改权重。

### 4.3 怎么读这张表

1. **降水维大幅回升**：中长期从 0~20 回到 46~55。这不是给模型加分，而是把“无技巧=0”改成“无技巧=50”。雨量仍然差、雨强仍然无技巧的模型，仍会被扣到 35~45。
2. **温度维中长期会降一些**：16 天日榜从约 52 降到 38，因为按气候平均参照，16 天的日最高/最低确实接近甚至低于气候平均。这不是新 bug，而是旧尺子把“3°C 误差”当成 55 分，本身就没有物理依据。
3. **综合分不再被单维拖死**：小时 16 天从 33.9 回到 49.4，日榜 16 天从 35.9 回到 47.8。中长期的“0 分”消失，变成 45~50 的“接近气候平均”。
4. **短时效不会暴涨**：小时 1 天综合 51.6→63.2，日榜 1 天 61.5→68.3；日榜 1 天页面显示仍会在 80 分附近（上端增益），不会出现“人人 95+”。

### 4.4 排名会怎么动

用当前分桶指标做降水维的“旧公式 vs 新公式”对拍：

- 小时榜 Spearman 中位 **0.847**，最低 0.497（11 天桶，n=12）；
- 日榜 Spearman 中位 **0.930**，最低 0.629（12 天桶）；
- 各桶前三名集合多数保持 2~3/3 不变，变化集中在中段。

这说明：**顶部名次大体稳定，中段会重排**。原因是旧公式在中长期把大量模型压成同一个低分/0 分，新公式恢复了它们的差异。按项目纪律，这属于“口径变更”，前后分数不可直接对比，需要重冻基线并在月报注明。

## 8. 一句话总结

**不是模型在中长期突然变差了，而是我们用了一把“0 分等于无技巧、50 分等于 ETS 0.415、温度 3.4°C、雨量 1.33 倍”的混杂尺子，再用展示增益把下半段压成 0。**

改成“50 分 = 气候平均 / 无技巧”之后，中长期降水会回到 46~55，综合分回到 45~50，0 分只留给真正比基准差一个灾难幅度的格。短期名次基本稳定，中段会重排；这是口径变更，需要重冻基线。
