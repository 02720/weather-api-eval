## 一、"全部纳入"为什么在恒等项上是数学上锁死的

加权和的每个槽位代表**一份独立证据**。若 y 是入分项的解析函数，y 的独立信息
严格为 0，给它一个权重就等于把同一份证据说两遍（[metric_coverage.md](metric_coverage.md)
已论证）。但"独立信息为 0"≠"不能出现在公式里"，看起来还有两条路：

| 写法 | 形式 | 实测结果 | 判定 |
|---|---|---|---|
| **残差当子分** | 加一项 `100 − \|y − ŷ\|×λ`，权重 0.05×4 | 综合分中位 50.88 → **55.27（+4.39）** | **失真**：dev 族把"残差=0"读成满分，于是"完全冗余"被记成"完美一致"，4 项白送 4.39 分 |
| **残差当零中心修正** | `score += ±λ(y − ŷ)`，残差 0 → 贡献 0 | 逐格偏移中位 **0.050** 分、最大 **0.157** 分；Spearman **1.0000**、冠军换人 0/30 | **等于没加**：偏移全是指标 round4 的舍入噪声，写进公式只是记账 |

第一条不是"调参没调好"，是**语义错**：一个恒等于 0 的量，放进"0 = 满分"的刻度里
必然拿满分。第二条是对的，但它的诚实结论是：**这一项在公式里的实际贡献恒为 0**。

所以恒等项只有一种诚实的处置——**照算、照列、在评分表里标注恒等式、权重 0**。
这不是保守，是它们的独立信息实测就是 0。

## 四、新发现一：温度的「站间一致性」是真维度（当前完全没测）

当前温度维所有指标都是**池化口径**：4 个站的误差先混成一个序列再算。这带来一个
结构性漏洞——**方向相反的站间系统偏差会相互抵消**。

实测（全窗口、28 源 × 4 站，`e2e_report.json` 的 `per_station`）：

| 量 | 跨源范围 | 与 \|池化 MBE\| 的相关 | 与池化 RMSE 的相关 |
|---|---|---|---|
| **各站 MBE 的样本量加权离散度** | **0.097 ~ 0.675（7.0×）** | **0.115** | 0.331 |
| 各站 slope 的离散度 | 0.019 ~ 0.178 | — | — |

关键数字是那个 **0.115**：站间一致性与当前入分的 \|MBE\| 几乎**正交**。也就是说
"池化偏差接近 0"完全不能推出"各站都不偏"。实例：

| 源 | 池化 MBE | 站间离散度 | 现状 |
|---|---|---|---|
| `accuweather_v1` | **+0.065**（几乎零偏差 → mbe 子分接近满分） | **0.292** | 靠站间抵消白拿分 |
| `qweather_v1` | **+0.034** | **0.247** | 同上 |
| `tj_t1h_ai` | −1.077 | 0.110 | 偏差大但各站一致（可业务订正） |

一个"各站都稳定偏 2°C"的源和一个"两站分别偏 +2 / −2"的源，当前评分给的分几乎
一样——但后者无法用单一订正量修好，业务价值完全不同。这是评分体系里**真实存在
的洞**，不是指标堆砌。

**可加性（能进 bootstrap 的硬前提）**：记各站误差和为 `E_s`、样本量 `n_s`，

```
between_var = [ Σ_s (E_s²/n_s) − (Σ_s E_s)²/N ] / N      N = Σ_s n_s
```

右端三项 `Σ_s E_s²/n_s`、`Σ_s E_s`、`Σ_s n_s` **全部可加**，温度聚合表只需从 11 列
扩到 12 列即可支持按天分块重采样。✅

**但代理口径不可用**：逐桶现成的 `r_pooled` / `slope_pooled` 也能反映站间不一致，
实测却不达标——

| 代理量 | 桶内跨源 sd | 相对 r 自身 sd | λ 反解后日轨子分 sd | 判定 |
|---|---|---|---|---|
| \|r − r_pooled\| | 0.006（h）/ 0.037（d） | 仅 **7% / 16%** | **12.29**（目标 8） | 信号弱 + 跨轨 1.5× |
| \|log₂(slope/slope_pooled)\| | 0.012 / 0.066 | 12% / 24% | **14.01** | 同上，1.75× |

把一个只有原信号 7~16% 强度的差，用 λ 强行放大到 sd=8，等于**把数值噪声放大成
话语权**。拒收代理口径，要加就加站级离散度本身。

## 五、新发现二：降水的「雨强分辨力」是真维度（分级指标从未入过分）

分级指标（hourly 1~5 级 / daily +1~+6 级，每级 7 项）此前只在明细表露过面。
实测各级 ETS 对晴雨 4 项的增量信息：

| 轨 | 级 | 1−R² | ρ(级 ETS, 晴雨 ETS) | 级 ETS 中位 |
|---|---|---|---|---|
| hourly | 1 | 0.116 | **+0.934** | 0.020 |
| hourly | **2** | **0.788** | +0.030 | 0.020 |
| hourly | **3** | **0.939** | +0.178 | 0.000 |
| hourly | 4 / 5 | 0.967 / 0.958 | 0.16 / 0.19 | 0.000 |
| daily | +1 | 0.032 | **+0.982** | 0.060 |
| daily | **+2** | **0.801** | −0.147 | 0.145 |
| daily | **+3** | **0.819** | +0.205 | 0.100 |
| daily | +4 / +5 | 0.855 / 0.945 | 0.08 / 0.15 | 0.045 / 0.000 |

两条结论：

1. **1 级 / +1 级 = 晴雨判定换了个说法**（ρ 0.93 / 0.98），不入分；
2. **2 级及以上与晴雨技巧近乎正交**（1−R² 0.79~0.97，ρ 只有 0.03~0.27）。
   "下不下雨报得准"和"下多大报得准"是**两种独立的能力**——当前评分只测了前者。

Q3 可靠性（λ 按"子分桶内跨源 sd = 8"反解后）：hourly 与 daily 子分 sd **均 = 8.00**，
跨桶 P90/P10 = **5.0 / 2.9**——优于现有入分项里最差的 BIAS（5.3）与 r（5.7），达标。

## 七、落地记录（2026-10-06，全部完成）

### 降水「雨强分辨力」`grade_ets`（w = 0.10，已上线）

* **口径**：中雨/大雨两档（逐小时 2~4.9 与 5~9.9 mm/h、按天 ≥10 与 ≥25 mm，阈值
  经 `stats.grade_bounds` 从 cyeva 配置模块单点读取）各自的 ETS，按该档**事件数**
  `h+fa+mi` 加权合并；某档事件数 < min_sample → 该档缺项，两档全缺 → 整维缺项
  （按剩余权重归一，绝不记 0 分）。
* **管线**：聚合表 `_RAIN_STATS` 7 → 13 列（两个雨强档各自的 h/fa/mi 计数），
  dict 版与列式版由 `test_daystats_columnar_matches_dict` 零容差锁定；分档二值化
  **统一用 `np.round(x, 1)`**（numpy 缩放舍入——Python 内置 round 在二进制边界上
  与它不一致，这是 `test_graded_parity.py` 里已有的口径钉子，见
  `test_grade_counts_match_cyeva`）。点估计与重采样共用同一个
  `grade_ets_from_counts`，逐位同尺。
* **λ 冻结**：两轨池化反解 **177.504**（分轨 hourly 4.17 / daily 10.50，跨轨比
  2.52×，与既有项 slope 的 2.27× 同量级——受"λ 按轨分别标定仍未做"的同一局限）。
* **权重**：原 6 项 ×0.9 等比缩放（ets 0.315 / pod·far·amt_mae 0.135 / bias·
  amt_bias 0.09），原配比不做二次改动。

### 温度「站间一致性」`mbe_bdisp`（w = 0.0625，已上线）

* **口径**：`between_var = [Σ_s(E_s²/n_s) − (Σ_s E_s)²/N]/N`，E_s = 该站误差和。
  **不需要扩聚合表**——逐站的 n 与 Σe 本来就在温度表的第 0/3 列，减法发生在
  站维归约之后即可（`E_s²/n_s` 不可逐记录累加，这正是它"可加"的正确写法）。
  点估计（`temp_metrics` 的 groups 路径）与重采样（`_temp_scores_from_aggregate`）
  共用 `between_station_mbe_sd`。
* **门槛**：只计入 `n_s ≥ GROUP_MIN_N(30)` 的站，达标站 ≥3 才出值，否则整维缺项
  （两点的"离散度"只是点距，受单站噪声支配，撑不起一致性命题）。
* **λ 冻结**：两轨池化反解 **36.098**（分轨 hourly 6.16 / daily 8.86，跨轨比
  1.44×）。
* **权重**：r 从 0.1875 → 0.125 让出 0.0625（r 与 slope 本就测同一件事的两个
  侧面、占着第二大权重）。**这是新的价值判断，已按口径变更流程记录于此。**
