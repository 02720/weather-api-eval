🧮 综合分怎么算：12 项指标的加权构成

🌡️ 温度分（7 项）

指标权重0~100 换算
±2°C 准确率25%百分比直接入分
RMSE 误差换算分25%100 − RMSE×5（0°C 记 100 分，每多 0.2°C 扣 1 分）
相关系数 r15%r×100（起伏节奏的同步程度）
±1°C 准确率10%百分比直接入分（更严格的命中口径）
MAE 误差换算分10%100 − MAE×5（典型误差，对偶发大误差不敏感）
偏差换算分10%100 − |MBE|×10（无系统性偏高/偏低 = 满分）
回归斜率换算分5%100 − |斜率−1|×100（冷热幅度恰如其分 = 满分）

不入分：RSS、χ²（样本量的函数，不是预报技巧）。

🌧️ 降水分（5 项，日雨量 ≥1.0mm 口径）

指标权重0~100 换算
晴雨 ETS 评分35%ETS×100（对“瞎蒙也能蒙对”做过校正，技巧首位）
晴雨 TS 评分25%TS×100（报中/空报/漏报一账清）
命中率 POD15%百分比直接入分（漏报少）
空报率换算分15%100 − FAR（不喊“狼来了” = 满分）
频率偏差换算分10%100 − |BIAS−1|×100（报雨频率恰如其分 = 满分）

不入分：晴雨准确率（由气候基率主导，ETS 已校正）、雨量误差 （被个别强降水时段主导，跨源比较不公平）。

某项缺数据时按剩余权重折算（缺数据 ≠ 差数据）；综合分 = 温度分与降水分各半。

📏 「能报 3 天的和能报 15 天的」为什么能同榜：难度对齐与名次的稳健性

越往后越难报，而各家能报的天数差很多：直接平均"自己覆盖的那几档"， 只报近几天的源白拿简单档的分。本页用双向加法劈分——把「（源 × 档位）」看成 分数 = 这家水平 + 这一档难度 + 噪声，用全部格子一起估出行、列效应， 数据一格不扔，也不要求各家覆盖一致。

这份名次有多结实？ ① 格子按 √(有效样本量) 加权，过薄格子剔除（本轮剔除 8 个）； ② 换成等权口径重算，名次 Spearman = 0.99（前十换 0 家）； ③ 分数方差拆解：源间 32% · 档位难度 46% · 交互与噪声 22%——残差占比越高，"一个数字排座次"抹掉的真实差异越多； ④ 有效样本量已扣除时间自相关与跨站相关（相邻站由同一批天气系统驱动，直接相加会高估约 1.7 倍）。

§02 · 理解

得分随时效衰减：谁"掉秤"掉得慢？

把每一档提前量的得分连成曲线。灰色地带是全体源的波动范围（虚线 = 中位）， 彩色粗线是总榜前三名；小时口径答"某日几点准不准"，日口径答"这一天的极值/总量准不准"， 两条曲线口径不同、不能互相比斜率。点图例可显示任意源。

💡 怎么看：线向右下掉是自然规律（越远越难报）；谁在右边还站得高， 谁的长期预报就更可靠。线中断 = 该时效样本不足。

§03 · 理解

温度与降水，分别准在哪？

逐小时口径、按提前天数（1~16 天）展开的单项指标。默认看总榜前三名， 点图例可加看任意源；温度与降水两页签可切换，指标下拉可换视角。

💡 怎么看：准确率/相关系数越高越好，RMSE/MAE/空报率越低越好； MBE 越接近 0 越好（正 = 习惯性报偏高，负 = 报偏低）；BIAS 越接近 1 越好。 降水比温度难报得多，TS 到 0.3~0.5 已属正常水平。

§04 · 理解

每一天的对账结果

每个格子 = 某天 × 某家预报源的温度准确率（±2°C），行按总榜名次排列。 绿 = 准，红 = 翻车，空白 = 数据不足。

💡 怎么看：整列发红往往是天气突变（大家都难），整行偏红才是这家整体拉胯。

§05 · 亲眼看看

最近 72 小时：预报 vs 实况

黑线 = 气象站实测气温，彩线 = 所选预报源，灰蓝柱 = 站点实测降水（右轴）。 彩线越贴近黑线越准。

§06 · 亲眼看看

同一个预报，在不同站点的表现

选一家预报源，看它在各观测站的表现差异（地形、气候不同会有差异）； 虚线 = 全体源在该站的中位水平。

🔬 这份名次有多结实？——诊断层的硬数字

同榜的 27 家，其实是几份独立证据？

各家预报的是同一批天气系统，它们的误差天然高度相关。 实测两两相关均值 ρ̄ = 0.608， 按 k_eff = m/(1+(m−1)ρ̄) 折算后的有效独立信源数约 1.61 家 ——榜单上看上去是 27 份证据，折算后只相当于约 1.61 份。这直接决定"第一名领先第二名"这句话的含金量。 显著性检验（† 标记）当前用的是保守口径 m （m = 28，k_eff = 1.61）： 保守口径宁可多说"说不清"，因为往 k_eff 方向放松会增加被判"与冠军有显著差异"的家数。

📖 名词小词典
起报 / 起报快照
预报发布的那一刻叫"起报"。每次起报的"未来 16 天逐小时预报"原样存档封存，等真实天气发生后对账——预报不能事后改，检验才算数。
时效（提前 N 天）
有效时刻 − 起报时刻 = "提前多久做的预报"，按日历天分桶；每个桶里同难度比较。
综合得分 / 温度分 / 降水分
多个指标压缩成 0~100：温度 7 项、降水 5 项加权，综合 = 两者各半；缺项按剩余权重折算。
难度对齐（总榜）
先把每一档提前量有多难算出来、统一扣掉再比（双向加法模型），能报 3 天的和能报 15 天的同榜也不吃亏。
覆盖时效
该源实际参与计算的样本最长覆盖到提前第几天。可用时效越少，总榜平均所依据的"桶"越少。
90% 置信区间与 †
对评估窗口内的天做分块重采样 500 次重算榜单得到的波动范围。名字带 † = 与第一名的差距经 Holm–Bonferroni 校正后仍与 0 分不开——不宜过度解读名次先后。
有效样本量 n_eff
逐小时误差强自相关，名义 n 会把同一信息重复计数；n_eff 按"每天真正带来多少新信息"折算，跨源比较请以它为准。
RMSE / MAE / MBE
温度误差的典型大小（°C，越小越好）：RMSE 对偶发大误差惩罚更重；MAE 是最朴素的"平均差多少度"；MBE 正 = 习惯性报偏高，负 = 报偏低。
相关系数 r / 回归斜率
r 越接近 1 越能跟上天气的"节奏"；斜率 >1 = 起伏幅度偏小（该热不热），<1 = 反应过激。
准确率（±1°C / ±2°C）
预报与实况相差不超过 1°C（或 2°C）的样本占比，越高越好。
命中率（POD）/ 空报率（FAR）
POD：真下雨的次数里预报也报出的比例（越高越好）；FAR：报了雨却没下的比例（"狼来了"次数，越低越好）。
TS / ETS 评分
命中 ÷（命中 + 空报 + 漏报），0~1，同时奖励报中、惩罚误报；ETS 对"瞎蒙也能蒙对"做过随机命中校正，更公平。
频率偏差（BIAS）
报雨次数 ÷ 实际下雨次数。=1 频率正好；>1 爱报雨；<1 不爱报雨。
日雨评分（TS/ETS）
降水分的口径是北京时自然日 24h 累计雨量 ≥1.0mm 记"有效降水日"（业务惯用口径）；24h 累计让毛毛雨超报在求和中自然抵消。
观测覆盖率
评估窗口内成功抓到实况的小时占比（实况接入前的时段不算缺失）；本窗口实况自 2026-09-01 起。
