🌱 30 秒看懂本报告

只需记住 5 个概念，遇到别的术语可直达页面底部 📖 名词小词典。

⏱️ 时效 = 提前量
预报是提前多久做的。提前 1 天大家都准，提前 10 天谁都难——本报告比的是谁"衰减得慢"。
🏅 综合得分
温度分（准确率+误差）与降水分（晴雨表现）各算一个 0~100 的分，再取平均。一项"瘸腿"拿不了高分。
🌡️ 温度准确率（±2°C）
预报温度与实况相差 不超过 2°C 就算报准。比例越高越好，100% = 满分。
📉 温度误差（RMSE）
温度平均报错了多少 °C，越小越好，0 = 完美。它对"偶尔离谱的大误差"更敏感。
🌧️ 晴雨评分（TS）
"下没下雨"报对程度的综合分（0~1），同时惩罚漏报和瞎报，越高越好。

🏅 预报源排行榜

按"提前 1 天（24 小时）以内"的预报表现打分排名（更长时效的走势见下一节）。 综合得分（0~100，越高越好）= 温度分与降水分的均分： 温度分 = 温度±2°C准确率 与 误差换算分（100 − RMSE×5，误差 0°C 记 100 分、20°C 记 0 分）的均分； 降水分 = 晴雨TS×100 与 晴雨准确率 的均分。样本不足的项不计入均分—— 单一要素缺数据的源按可用维度计分照常参评，缺失维度显示 —（灰纹条）。

📉 得分随时效衰减：谁"掉秤"掉得慢？

排行榜只看"提前 1 天"，这一节把每一档提前量（第 1~16 天）的得分都算出来画成曲线。 同一套打分公式（综合 = 温度分 + 降水分），切换下方维度：

💡 怎么看：所有曲线都会往右掉（提前量越大、预报越难），谁掉得慢、谁在右边还站得高， 谁的中长期预报就更可靠。某条线中途断掉 = 该时效"样本不足"（还没有那么多天的数据，攒着攒着就有了）。

🌡️ 气温预报准不准？

横轴是"预报提前量"（往右 = 预报更久以后的天气），每条线是一家预报源，按排行榜顺序排列。 右侧指标下拉可切换温度的全部指标。

💡 怎么看：准确率/相关系数越高越好，RMSE/MAE/MBE 越低越好。 所有线都会往右掉（预报越远越没准头），谁掉得慢、谁在右边还高高在上，谁的中长期预报就更可靠。 默认只画前 8 名（23 家全画会糊成一团），点右侧"全部"或图例可自行增减。

🌧️ 下雨预报准不准？

把"降水量 ≥ 0.1mm"记为"有雨"。指标下拉可切换降水的全部指标 （晴雨评分族 + 降水量误差族）。分级降水（小/中/大/暴雨）见页面下方"进阶数据"。

💡 怎么看：TS / ETS / 准确率 / 命中率越高越好；空报率、漏报率越低越好； 频率偏差 BIAS 越接近 1 越好（>1 = 爱报雨，<1 = 不爱报雨）。 降水比温度难报得多——TS 到 0.3~0.5 已属正常水平，各家普遍不高不是报错了，而是下雨本身就难预测。

🔍 亲眼对比：预报 vs 实况（最近 72 小时）

不看指标，直接用眼睛检验：黑线是气象站实测气温，彩线是预报（取每个时刻当时已发布的最新一版），蓝柱是预报降水量（右轴）。

💡 怎么看：彩线越贴近黑线越准。可以切换不同站点和预报源， 看看谁家能跟上气温的起伏节奏（尤其是每天最高/最低点的位置和幅度）。

📖 名词小词典

页面里出现的术语，全部用大白话解释一遍。

起报 / 起报快照
预报发布的那一刻叫"起报"。我们把每次起报的"未来 16 天逐小时预报"原样存档封存，等真实天气发生后再对账——预报不能事后改，检验才算数。
时效（lead）
有效时刻 − 起报时刻，即"提前多久做的预报"。"3 天时效" = 提前 3 天报的。
天桶
把时效按天分组：提前 1~24 小时算"第 1 天桶"，25~48 小时算"第 2 天桶"，以此类推。
综合得分 / 温度分 / 降水分
把多个指标压缩成一个 0~100 的总分方便排名。温度分 = 温度±2°C准确率与误差换算分（100−RMSE×5）的均分；降水分 = 晴雨TS×100 与晴雨准确率的均分；综合得分 = 两者均分。
RMSE（均方根误差）
温度误差的"典型大小"，单位 °C，越小越好。比起 MAE，它对偶尔的大误差惩罚更重。
MAE（平均绝对误差）
每次预报误差绝对值的平均，单位 °C，越小越好。最朴素的"平均差多少度"。
MBE（平均偏差）
预报 − 实况的平均值。正数 = 习惯性报偏高，负数 = 报偏低，接近 0 最好。
RSS（残差平方和）
所有样本误差的平方加总（°C²）。是 RMSE 的"未开方、未平均"版本，样本越多天然越大，只适合同一样本数的横向对比。
χ²（卡方）
误差平方的平均（°C²），即 MSE。与 RMSE 的关系：RMSE = √χ²。越小越好。
相关系数 r
预报与实况起伏的同步程度（−1~1）。越接近 1，预报越能跟上天气的"节奏"；接近 0 = 报了个寂寞。
回归斜率
以预报为横轴、实况为纵轴做回归的斜率。>1 = 预报的起伏幅度偏小（该热不热该冷不冷）；<1 = 预报反应过激；=1 最理想。
准确率（±1°C / ±2°C）
预报与实况相差不超过 1°C（或 2°C）的样本占比，越高越好。
晴雨
把降水简化成是非题：降水量 ≥ 0.1mm 算"有雨"，否则"无雨"。
晴雨准确率
上述是非题"答对"的比例（报有雨确实下了 + 报没雨确实没下），越高越好。
命中率（POD）
实际真的下雨的次数里，预报也报雨的比例。越高 = 漏报越少。
空报率（FAR）
预报说会下雨的次数里，实际没下的比例。越低越好（"狼来了"次数）。
空报频率（POFD）
实际没下雨的次数里，预报却报了雨的比例（与空报率分母不同）。越低越好。
漏报率
实际下雨但预报没报出来的比例，越低越好。与命中率互补：漏报率 = 1 − POD。
TS 评分
命中 ÷（命中 + 空报 + 漏报），0~1。降水检验最常用的综合分，同时奖励报中、惩罚误报。
ETS 评分
对 TS 做"随机命中校正"的版本（0~1）。考虑"瞎蒙也能蒙对一部分"，ETS 更公平：瞎蒙的预报 ETS≈0，好预报才为正。
频率偏差（BIAS）
报雨次数 ÷ 实际下雨次数。=1 频率正好；>1 爱报雨；<1 不爱报雨。
雨量误差（RMSE / MAE / MBE）
不只看下没下，还看预报的降水量数值差多少（mm），越小越好。降水数值比晴雨难报得多。
雨强分级（1h 口径）
按每小时雨量分档检验：小雨(0.1~1.9mm/h)、中雨(2~4.9)、大雨(5~9.9)、暴雨(10~19.9)、大暴雨(≥20)。每档可算全套晴雨类指标。
累计分级（24h 口径）
按日累计雨量"达到某档以上"检验：≥0.1（小雨以上）、≥10（中雨以上）、≥25（大雨以上）、≥50（暴雨以上）、≥100（大暴雨以上）、≥250mm（特大暴雨以上）。
样本数 n
参与指标计算的"预报-实况"对数。n < 5 时本报告判"样本不足"，不下结论（显示 —）。
观测覆盖率
评估窗口内成功抓到实况的小时占比。覆盖率低会让指标样本变少。
